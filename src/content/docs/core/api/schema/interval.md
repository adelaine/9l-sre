---
title: Interval
description: Interval purpose and relationships in the issue tracker.
---

Represents a planning cycle that groups issues within a workspace.

## Relationships

- An interval belongs to exactly one workspace.
- An interval groups zero or more issues.
- An issue can belong to at most one interval, within the same workspace.
- An issue can remain outside an interval.
