---
title: Glossary
description: Shared project and domain terminology.
---

| Term          | Meaning in this project                                                                                         |
| ------------- | --------------------------------------------------------------------------------------------------------------- |
| 9L-SRE        | Nine Lives: Spectral Reliability Engineering, the incident-response demo.                                       |
| Operative     | A fictional cat member of the response team. A story role does not automatically grant application permissions. |
| API           | Application programming interface; the contract through which the clients will communicate with Core.           |
| ClientJ       | The planned Jira-inspired Angular application.                                                                  |
| ClientL       | The planned Linear-inspired React Router and Redux application.                                                 |
| Core          | The planned shared Java and Spring Boot backend.                                                                |
| Digital ghost | The fictional cause of unusual infrastructure behavior in the demo setting.                                     |
| Incident      | A report of suspected digital ghost activity and the work toward its resolution.                                |
| Reporter      | Someone who submits a sighting and follows its resolution.                                                      |
| Reset         | Restoration of the demo's original seeded state; exact scope remains to be defined.                             |
| Seed data     | Initial records used to create a repeatable demo starting point.                                                |
| SRE           | Site Reliability Engineering, the real-world discipline referenced by the project's name.                       |

See the [project overview](/getting-started/overview/) for scope and the [world-building appendix](/appendix/) for the fictional setting.
