ClientL is the planned React frontend in `9l-sre-clientl`. It uses React Router for routing and Redux for application state. Tailwind CSS is part of the original React demo direction.

## Intended experience

ClientL takes interface inspiration from Linear. The proposed experience emphasizes a focused incident collection, clear details, and efficient movement through reporting and investigation. Exact layouts and interaction patterns remain to be designed.

It is intended to use the same Core backend as ClientJ. This gives the project a common domain for comparing React and Angular implementation choices.

## Implementation status

The repository is currently empty. Package versions, React Router mode, data-fetching strategy, and deployment have not been specified. Linear inspiration does not imply a Linear integration or full feature parity.
